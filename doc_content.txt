HMS ↔ App API Integration — API Documentation
API-1 — Patient Registration / Patient Match
Purpose
Create a new patient in HMS or find an existing patient using Name + Middle Name + Last Name + DOB + Mobile.
API Link
https://tulasihms.in/hms/api/patientdata
Method
POST
Request Body — Fields to be filled
{    "name": "RAHUL",    "middle_name": "",    "l_name": "BAHEL",    "dob": "1999-06-22",    "phone": "8800100247",    "address": "Jaipur",    "branch_id": "1"}
Output — JSON
{    "status": "ok",    "statusCode": "yes",    "error": "",    "message": "Existing patient found",    "data": {        "patient_id": "254",        "uhid": "2024RG247",        "name": "RAHUL",        "middle_name": "",        "l_name": "BAHEL",        "dob": "1999-06-22",        "phone": "8800100247"    }}
API-2 — Admission Status Push
Purpose
Retrieve the patient's IPD admission information, including doctor, ward, admission status, complaint and visit date.
API Link
https://tulasihms.in/hms/api/admissionStatusPush
Method
POST
Request Body — Fields to be filled
{    "uhid": "2026-27RG7930"}
Output — JSON
{    "status": "ok",    "statusCode": "200",    "error": "",    "message": "Patient admission data found",    "data": {        "uhid": "2026-27RG7930",        "patient_id": "9665",        "name": "RAHUL YADAV",        "middle_name": "",        "l_name": "",        "dob": "2007-07-11",        "phone": "8824485239",        "address": "Jaipur",        "care_team": "Dr. Example",        "admitting_complaint": "Fever",        "ward": "General Ward",        "admission_status": "Admitted",        "visit_date": "2026-09-23 10:30:00"    }}
API-3 — Discharge Summary Push
Purpose
Send/retrieve the patient's discharge summary and discharge-related information when an IPD patient is discharged.
API Link
https://tulasihms.in/hms/api/dischargeSummaryPush
Method
POST
Request Body — Fields to be filled
{    "uhid": "2026-27RG7930"}
